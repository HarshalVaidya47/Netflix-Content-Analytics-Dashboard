# Power-Bi-Projects
Power BI Dashboard Projects Done By Me

🚀 Excited to share my latest **Power BI project – Netflix Content Analytics Dashboard**!

This dashboard provides a comprehensive view of Netflix's content library, helping users explore trends, content distribution, and viewing insights through interactive visualizations.

📌 **Key Features**
🔹 Filters by **Content Name** and **Content Type**
🔹 KPI Cards:
• Total Content
• Movie Count
• Average Movie Runtime (Minutes)
• TV Show Count
• Average TV Show Seasons

📊 **Visual Insights**
• Movie Runtime Distribution by Hourly Range
• TV Show Season Breakdown
• Yearly Content Release Trends
• Content Count Analysis
• Show Distribution by Rating

Through this project, I enhanced my skills in **Power BI, Data Modeling, DAX, Power Query, and Dashboard Design**, transforming raw data into meaningful business insights.
